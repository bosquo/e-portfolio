## 🚀 Hosting on GitHub Pages

1. Create a new repository on GitHub (e.g. `<username>.github.io` or `e-portfolio`).
2. Push this folder:
   ```powershell
   git init
   git add .
   git commit -m "Florian Herbst e-Portfolio"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
3. In your GitHub repository, go to **Settings → Pages**, choose **Deploy from a branch** (`main` / `root`), and click **Save**.
